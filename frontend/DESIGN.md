# 好球：篮球进球剪辑聊天页

依据任务计划 v0.4 与公开 frontend-design SKILL.md（https://raw.githubusercontent.com/anthropics/skills/main/skills/frontend-design/SKILL.md，2026-11-26 读取）。本轮已授权直接执行，以下视觉选择由前端自行确定。

## 视觉 tokens
- 场外雾蓝 #edf2f5：页面底色；白线 #ffffff：聊天底面。
- 海军蓝 #19334a：文字与球场线；篮球橙 #b84316：主要操作（白字对比）。
- 线灰 #ced9e1：分隔；草绿 #256249：完成状态。
- 标题 Arial Narrow / Impact / sans-serif，中文标题与正文用 Microsoft YaHei / PingFang SC / sans-serif。正文 15px，行高 1.7；标题 38px，手机 30px。时间点用表格数字。
- 间距 8/12/20/32/48px，交互最小高度 44px。聊天文本宽度控制在 65 字符内。

## 布局
桌面左侧 300px 固定引导，右侧流式聊天，最多 1180px；手机单列，压缩引导但保留欢迎与上传入口。全部左对齐。
```
[ 篮球图形 / 好球                     服务阶段 ]
[ 欢迎 / 能力边界 ] [ 消息流 / 进球结果       ]
[ 限制 / 上传入口 ] [ 快捷指令               ]
[ 默认片段说明    ] [ 输入框 / 发送           ]
```
方案对比：全屏 IM 易隐藏首次引导；仪表盘增加不必要导航；选用场边引导 + 单个聊天，首次进入与持续修改都有明确入口。

## 原则与复核
唯一强视觉是用真实篮球弧线构成的品牌图形。其余内容保持安静，不增加营销指标、装饰标签或假数据。橙色只标示可操作内容，不把页面做成泛用深色运动模板。编号只用于按源时间排列的真实进球。状态、错误、上传进度、结果均在聊天区域；不增加账户、版本、审片页。欢迎立即本地渲染，配置失败时明确无法获取限制。键盘焦点可见，尊重 reduced-motion。
